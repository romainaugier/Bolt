# Flash
DDAGs for easy task automation, written with Python 3.9.

Dependencies :
- Python 3.9+ 
- PyQt5
- Colorama


## Description
Flash was designed to ease task automation by enabling users to create various graphs to suit their production pipeline and quickly prototype workflows. More advanced users such as tds and developers can also benefit a lot from using Flash as it can help by having a visual representation of the pipeline flow, and ease the development process by avoiding coding repetitive functions. It can fit any production as the nodes are customizable and new ones can be created very easily with a few lines of python code.
