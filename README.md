# Bolt
Acyclic node graphs for easy task automation.

Dependencies :
- Python 3.9.7 
- PyQt5
- Colorama
- PyInstaller (required if you want to build the executable)


## Description
Bolt was designed to ease task automation by enabling users to create various graphs to suit their production pipeline and quickly prototype workflows. More advanced users such as technical directors and developers can also benefit a lot from using Bolt as it can help them having a visual representation of the pipeline flow, and ease the development process by avoiding coding repetitive functions and processes. It can fit any production as the node library can be easily extended, maintained and customized.
